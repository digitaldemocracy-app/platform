# Code of conduct

The platform's fifth principle applies to its own repository: **debating is not fighting.**

- Argue about code, design and evidence. Do not attack people.
- Disagreement is welcome and expected; abuse, harassment, discrimination and manipulation are not.
- This project takes no side for or against any party, candidate, government or ideology, and neither does its issue tracker. Partisan content is off topic and will be closed.
- Everyone can participate in any language; English is the working language of the code and the documents.
- Moderation decisions are made in the open: a closed issue says why it was closed. Nothing is deleted in silence.

Reports: open a private vulnerability report (see [SECURITY.md](SECURITY.md)) if it is sensitive, or an issue if it is not. The maintainers act within seven days.

This document is deliberately short. It will grow only if practice shows it needs to.

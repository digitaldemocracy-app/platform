# @digitaldemocracy/web

Public landing page for Digital Democracy (Next.js 15, App Router, Tailwind CSS 4). Statically exported (`output: 'export'`) for Cloudflare Pages. No business logic yet.

Requires Node 22 (see `.nvmrc`). Setting `NEXT_TELEMETRY_DISABLED=1` is recommended.

## Commands

- `npm ci` install dependencies
- `npm run dev` start the dev server
- `npm run lint` / `npm run typecheck` / `npm test`
- `npm run build` static export to `out/`
- `npm run preview` serve `out/` locally
